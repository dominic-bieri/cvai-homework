# cvai-homework

## Installation

mac, linux:
```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

windows: 
```sh
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
